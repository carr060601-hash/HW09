## 一、作業說明
使用 Python 整理桌遊體驗與電影欣賞兩場活動的報名資料，統一姓名格式、去除重複報名，計算參加人數與應收費用。

## 二、程式功能
- 使用 tuple 儲存活動名稱。
- 使用 list 儲存整理後的原始名單。
- 使用 set 去除重複姓名並比較兩場參加者。
- 使用 dict 儲存活動費用與統計結果。
- 使用 sorted() 排序，並以切片取得通知名單前兩位。

## 三、三組測試結果

| 測試 | 桌遊人數 | 電影人數 | 共同人數 | 總不重複人數 | 報名人次 | 總應收 |
|---|---|---|---|---|---|---|
| 測試一 | 3 | 3 | 1 | 5 | 6 | 600 元 |
| 測試二 | 3 | 4 | 1 | 6 | 7 | 680 元 |
| 測試三 | 3 | 3 | 3 | 3 | 6 | 600 元 |

三組測試皆使用 Python 程式計算，並保留實際執行結果。

## 四、個人回答

### 問題一
測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？

因為 Amy 和 amy 經過小寫轉換後會變成同一個名字。list 會保留重複資料，但 set 會自動去除重複，所以桌遊實際只有 amy、ben、cora 三位參加者，因此應收費用是 3 × 120＝360 元。

### 問題二
測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次，總應收仍是 600 元？

因為三個人都參加了兩場活動，所以總不重複人數是 3 人，但每個人各報名兩場，因此報名人次為 6 人次。桌遊收費 3 × 120＝360 元，電影收費 3 × 80＝240 元，總應收為 600 元。
